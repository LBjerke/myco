# Zero Zig Navigation Guide

This mini-doc set helps readers with zero Zig experience navigate the Myco repo. It focuses on how to read the code and where to look for each feature.

## Suggested reading order

1) docs/zero-zig/zig-primer.md
- Zig syntax basics for reading code.

2) docs/zero-zig/repo-tour.md
- A guided map of the directories and key files.

3) docs/zero-zig/data-flow.md
- How the daemon boots, gossips, and deploys services.

## Useful existing docs

- docs/architecture.md: system overview and data flow.
- docs/GLOSSARY.md: terms used in the codebase.
- docs/quickstart.md: basic build/run steps.
- docs/testing.md and docs/TESTS.md: how tests are wired.
- docs/ENV.md: env vars that change behavior.

## How to use this guide

- Start with the Zig primer to decode syntax and idioms.
- Use the repo tour to find the right file quickly.
- Use the data flow doc to connect modules into a single mental model.

If you get lost, jump back to docs/architecture.md to re-anchor the big picture.
